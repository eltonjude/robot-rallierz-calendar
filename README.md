# Robot Rallierz Calendar

This is the team calendar for Robot Rallierz (VEX IQ, The Husky Pack).

Subscribe with this URL:

https://raw.githubusercontent.com/eltonjude/robot-rallierz-calendar/main/calendar.ics

## How to subscribe

**Google Calendar:** Other calendars > + > From URL

**Apple Calendar on iPhone:** Settings > Calendar > Accounts > Add Subscribed Calendar

**Apple Calendar on Mac:** File > New Calendar Subscription

**Outlook:** Add calendar > Subscribe from web

Subscribed calendars refresh on the app's own schedule. Google Calendar can take up to a day to show updates.
